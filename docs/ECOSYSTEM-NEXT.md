# Ecosystem pass — 2026-10-27

- 8,000 default game fish; seven profiles in `godot/assets/generated/ecosystem-config.json`: redfish, speckled trout, snook, sheepshead, tarpon, jack crevalle and flounder. Profiles configure size, depth, speed, habitat, prey-size ratio, schooling and home radius. These are authored gameplay heuristics, not calibrated biology.
- Existing water graph reused: 1,380 regions, 4,140 resting/feeding/hunting spots on validated corridors. Shoreline, depth relief, existing structures and flowlines identify holding-area candidates. Grass, mangrove, pothole and oyster labels are inferred; no new habitat survey was acquired.
- Persistent home/preferred spots, staggered two-hour routines, probabilistic choices, hunger overrides, species/size-dependent schools and individual IDs. Navigation returns through region centers; no straight shortcuts across land. Nearby fish receive finer updates; distant fish use existing bounded batches.
- 2,760 persistent forage pods: fry, scaled sardines, mojarra, pinfish, shrimp, crabs, small/large mullet. Quantity and size control feeding. Mullet consume abstract algae/detritus, jump and scatter. Oyster candidates provide stationary replenishing benthic food. Near-player consumption checks individual game-fish range against prey pods/other fish; distant interactions use region quantities. Forage remains aggregated, even near the player.
- Default predator ratio 1:100 (80 individuals for a new population), adjustable 0–3:100 in config, 0–2:100 in the developer panel. Bull, blacktip and bonnethead shark profiles plus bottlenose dolphins in pods. Predators consume prey, produce decaying local pressure, disrupt schools and displace game fish. Preferred spots remain available for later returns.
- Predation permanently marks consumed game fish; their ID and last location remain inspectable. No ID recycling, automatic game-fish respawn, growth or reproduction. Forage has slow abstract recruitment. Living populations can decline in long accelerated sessions.
- Version 3 saves include individual routines, schools, forage, predators, pressure, tide/current and random state. Previous three-species saves retain their records and gain 400 fish across the four missing species. Incompatible saves disable writing instead of overwriting the original. Simulation does not run while the game is closed.
- Adjustable ecology tide offsets depth suitability/accessibility at region centers; configurable uniform current influences travel. This does not change rendered shorelines, boat physics or implement real tidal flows / corridor drying.
- F4: density/species, food, suitability, pressure, habitat and school/prey views. Click rings/triangles to inspect forage/predators. Search a game-fish ID, inspect routine and school members, replenish food, apply a temporary scare, accelerate time and return to the same fish. Golden squares mark the selected fish's home/preferred regions. The Observe button sets 60× and replenishes its feeding region; outcomes remain probabilistic.

Only script compilation/build checks were used for this pass. No gameplay smoke tests, benchmarks or broad suites were run, as requested. Gameplay balance, visual layout and long-session behavior are left for user testing. Existing launcher remains the live-source entry point; the Windows export is updated separately.
